# Fiches de fonctionnalités

Une fiche par fonctionnalité, **toutes sur le même gabarit** (11 sections, dans cet ordre) :

1. **Objectif** · 2. **Périmètre** · 3. **Vue d'ensemble technique** (schéma Mermaid) · 4. **Composants et fichiers concernés** · 5. **Entrées / sorties** · 6. **Fonctionnement détaillé** (avec pseudo-code) · 7. **Dépendances** · 8. **Cas limites et erreurs** · 9. **Tests** · 10. **Pièges et dette technique** · 11. **Pour modifier ou étendre**.

Chaque fiche commence par une ligne `**État :** Implémentée | Partielle | Prévue` et la date de dernière vérification contre le code. La convention de pseudo-code est décrite dans le [plan de documentation](../plans/plan-documentation.md). Contrôlé par `tests/docs.test.js`.
